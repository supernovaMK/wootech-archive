# 우아한테크코스 7기 백엔드 학습 정리
우아한형제들에서 주관하는 우아한테크코스에서 10개월간 백엔드 개발자의 역량을 쌓았습니다.
<br>
객체지향, 클린코드,페어프로그래밍 부터 시작해서 코드리뷰 등 더 나은 소프트웨어 개발은 무엇일까를 고민하며 공부했습니다.

<br>

## 레벨 1: Java 학습

JAVA를 사용하여 각 미션의 어플리케이션을 개발하였습니다.
각 미션에서의 PR에서는 코드리뷰를 통해 리뷰어와 대화한 내용들을 확인하실수 있습니다.

| 프로젝트 | 키워드 | 1단계 | 2단계 | 
| :---: | :---:  | :---: | :---: |
| 로또 | 단위테스트 | [로또 구현](https://github.com/woowacourse/java-lotto/pull/591) | [로또 리팩터링](https://github.com/woowacourse/java-lotto/pull/612) |
| 출석 체크 | TDD | [출석 구현](https://github.com/woowacourse/java-attendance/pull/8) | [출석 다시 구현하기](https://github.com/woowacourse/java-attendance/pull/107) |
| 블랙잭 | CleanCode | [블랙잭 구현](https://github.com/woowacourse/java-blackjack/pull/800) | [블랙잭 베팅](https://github.com/woowacourse/java-blackjack/pull/906) |
| 장기 | OOP, DB | [장기 구현1](https://github.com/woowacourse/java-janggi/pull/3) | [장기 구현2](https://github.com/woowacourse/java-janggi/pull/123) |
